software is conveyed. Separately, section 13 applies if you modify the Program
and your modified version supports interaction through a computer network: the
modified version must prominently offer every user interacting with it remotely
an opportunity to receive that version's Corresponding Source, without charge,
from a network server through a standard or customary means of copying
software. Section 13 does not state that merely operating an unmodified AGPL
Program over a network triggers that source-offer requirement. Consult the

## Generated applications

`pliego new` does not automatically license an application's new original code,
content, brand, or assets. Generated projects contain `LICENSE.md` as an
explicit placeholder. Their authors must choose and install an application
license before distribution. Unmodified template code remains AGPL-covered; the
placeholder is not an exception or relicensing grant for copied PliegoRS
template code. This preserves ownership of genuinely original user work, but it
does not waive obligations that may arise when an application is distributed as
a derivative or combined work with AGPL-covered PliegoRS software.
